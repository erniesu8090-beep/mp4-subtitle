# MP4 Subtitle Embedder (MP4 影片鑲嵌字幕工具)

一個基於 Flask 與 FFmpeg 的網頁介面工具，用於快速將 `.srt` 字幕檔鑲嵌到 MP4/MKV 影片中。支援「硬字幕（內嵌）」與「軟字幕（封裝，不重新編碼）」兩種模式，並提供繁體中文網頁操作介面。

## 功能特色
1. **本地原生檔案選取**：使用系統內建檔案選取視窗（Tkinter Dialog），無需上傳龐大的影片檔案，點選即可直接定位路徑。
2. **自動匹配字幕**：選擇影片後，程式會自動在相同目錄下搜尋同名或帶有語言後綴（例如 `.zh`、`.tw`、`.cht`、`.en` 等）的 `.srt` 字幕檔案。
3. **兩種嵌入模式**：
   - **硬字幕 (內嵌)**：將字幕直接渲染至影片畫面中（需要重新編碼），可自訂字型、字體大小、顏色及背景樣式（描邊、不透明背景框、無背景）。
   - **軟字幕 (封裝)**：直接將字幕軌加入影片容器中（無須重新編碼影片，极速完成）。
4. **即時進度與日誌監控**：使用 Server-Sent Events (SSE) 技術，提供實時進度條、當前轉碼 FPS、處理速度（x倍速）以及 FFmpeg 的詳細執行日誌。
5. **快速開啟定位資料夾**：影片處理完成後，可一鍵透過檔案總管開啟並直接選取該輸出檔案。
6. **自動啟動**：啟動後會自動延遲並開啟預設瀏覽器進入 `http://127.0.0.1:5000` 操作頁面。

## 系統需求
- **Python 3.x**
- **FFmpeg & FFprobe**：需下載並加入系統環境變數 `PATH`，以便程式能夠調用 `ffmpeg` 與 `ffprobe` 指令。

## 安裝與執行步驟

### 1. 安裝 Flask
本專案僅依賴 `Flask` 框架來提供 Web 介面。在終端機中執行以下指令進行安裝：
```bash
pip install Flask
```

### 2. 啟動服務
#### Windows 系統：
直接雙擊執行 [run.bat](file:///c:/Users/ernie/Documents/MP4鑲嵌字幕/run.bat)，或在終端機中執行：
```cmd
run.bat
```

#### macOS / Linux 系統：
在終端機中進入專案目錄，並執行：
```bash
python app.py
```
啟動後，程式會自動開啟瀏覽器並連結至 `http://127.0.0.1:5000`。

## 進階硬字幕設定
在「硬字幕」模式下，您可以調用以下進階設定以符合影片風格：
- **字型 (Font Name)**：預設使用微軟正黑體 (`Microsoft JhengHei`)，可輸入系統內已安裝的其它字型。
- **字體大小 (Font Size)**：自訂字幕點數大小。
- **字體顏色 (Font Color)**：白色 (White)、黃色 (Yellow)、青色 (Cyan)、紅色 (Red)、綠色 (Green)、藍色 (Blue)。
- **背景樣式 (Background Style)**：
  - `Outline`：文字描邊與陰影效果。
  - `Opaque`：半透明黑色背景條框。
  - `None`：純文字，無描邊無背景。
- **垂直邊距 (Margin V)**：字幕距離影片畫面底部的垂直像素高度。
